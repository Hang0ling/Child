# IGS-S5-02 镜像对方原话而不是急着解释

- 阶段：S5 私信熟悉与倾听策略
- 目标：提高后续对话率、开启私信对话、建立长期朋友关系
- 内容形式：私信策略
- 用户心理：提升被理解感、提升安全感、降低怀疑感
- 资料来源：Never Split the Difference (Chris Voss)、Nonviolent Communication (Marshall Rosenberg)、Everybody Writes (Ann Handley)

## 核心判断

私信是更高亲密度空间，必须先让对方有选择权和安全感。对方在私信里最先需要被听见；镜像原话能让对方继续展开真实问题。执行时只把它当作建立熟悉感和互相信任的入口，不把对方当作被推进的对象。

## 关系应用

用于在社交平台上认识合适的陌生人，通过公开互动、真诚倾听和小范围互助，逐步成为朋友并赢得长期信任。

底线：必须真实透明、尊重对方选择；不伪装身份、不套取隐私、不制造虚假亲密或焦虑，对方冷淡、拒绝或沉默时停止推进。

## 执行动作

1. 复制对方关键短语并轻轻追问，例如“你说‘不知道怎么开始’？”
2. 避免马上给长篇方案，先确认问题、目标和限制。
3. 把对方原话沉淀到语言库，后续用于内容和 FAQ。
4. 边界要求：必须真实透明、尊重对方选择；不伪装身份、不套取隐私、不制造虚假亲密或焦虑，对方冷淡、拒绝或沉默时停止推进。

## 观察指标

- 二次回复率
- 对方补充信息长度
- 对话中断点
- 对方主动回应率
- 重复互动率
