# IGS-S2-08 制作 Start Here 新手导览

- 阶段：S2 主页可信与安全感策略
- 目标：提升主页可信感、降低陌生防备、建立长期朋友关系
- 内容形式：Highlights 策略、Carousel 策略、Story 策略
- 用户心理：降低陌生感、提升安全感、提升持续关注理由
- 资料来源：[Later Instagram Guides](https://later.com/resources/guide/)、[Hootsuite Instagram Resources](https://blog.hootsuite.com/network/instagram/)、Building a StoryBrand (Donald Miller)

## 核心判断

陌生人点进主页时，会先判断你是否真实、安全、值得回应。新访客需要被带路；一个清楚的 Start Here 能把碎片内容串成路径。执行时只把它当作建立熟悉感和互相信任的入口，不把对方当作被推进的对象。

## 关系应用

用于在社交平台上认识合适的陌生人，通过公开互动、真诚倾听和小范围互助，逐步成为朋友并赢得长期信任。

底线：必须真实透明、尊重对方选择；不伪装身份、不套取隐私、不制造虚假亲密或焦虑，对方冷淡、拒绝或沉默时停止推进。

## 执行动作

1. 做一条 6-8 页 Carousel：你适合谁、先看什么、常见问题、下一步。
2. 把它置顶，并拆成 Story 加入 Start Highlight。
3. 每次账号定位调整后同步更新导览，避免旧内容误导新认识的人。
4. 边界要求：必须真实透明、尊重对方选择；不伪装身份、不套取隐私、不制造虚假亲密或焦虑，对方冷淡、拒绝或沉默时停止推进。

## 观察指标

- Start Here 完读率
- 导览后关注率
- 导览后私信率
- 对方主动回应率
- 重复互动率
