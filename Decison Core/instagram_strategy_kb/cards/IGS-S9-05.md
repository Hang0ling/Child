# IGS-S9-05 建立说服伦理清单

- 阶段：S9 学习提升策略
- 目标：提升主页可信感、建立长期朋友关系、提高后续对话率
- 内容形式：私信策略、资源互助策略、Bio 策略
- 用户心理：提升安全感、降低怀疑感、提升互惠感
- 资料来源：Influence (Robert Cialdini)、Pre-Suasion (Robert Cialdini)、Nonviolent Communication (Marshall Rosenberg)

## 核心判断

学习提升要服务更真诚、更稳定的关系能力，而不是堆技巧。说服技巧必须服务对方利益；透明、可选择和不夸大，是长期信任的底线。执行时只把它当作建立熟悉感和互相信任的入口，不把对方当作被推进的对象。

## 关系应用

用于在社交平台上认识合适的陌生人，通过公开互动、真诚倾听和小范围互助，逐步成为朋友并赢得长期信任。

底线：必须真实透明、尊重对方选择；不伪装身份、不套取隐私、不制造虚假亲密或焦虑，对方冷淡、拒绝或沉默时停止推进。

## 执行动作

1. 每次活动前检查：是否夸大结果、是否隐藏条件、是否制造不必要焦虑。
2. 小资源和私信里说明适用对象和不适用对象。
3. 所有紧迫感、社会认同和权威证明都必须真实可解释。
4. 边界要求：必须真实透明、尊重对方选择；不伪装身份、不套取隐私、不制造虚假亲密或焦虑，对方冷淡、拒绝或沉默时停止推进。

## 观察指标

- 对方投诉数
- 取消关注率
- 信任类反馈
- 对方主动回应率
- 重复互动率
