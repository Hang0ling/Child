# IGS-S6-G12 挑战型小资源

- 阶段：S6 小资源互助策略
- 目标：提升主页可信感、建立长期朋友关系
- 内容形式：Carousel 策略、资源互助策略
- 用户心理：提升参与感、提升持续关注理由
- 资料来源：[CXL Institute](https://cxl.com/institute/)、[Later: How to Plan an Instagram Stories Campaign](https://mktg-cdn.later.com/ebooks/Later_How-to-Plan-an-Instagram-Stories-Campaign.pdf)

## 核心判断

小资源和小帮助用于降低对方行动负担，不用于制造亏欠感。对方需要陪伴而不是小资源时，小资源要制造可完成的小胜利，而不是堆砌看似丰富的小资源；“挑战型小资源”的作用是把这个判断变成一个可执行、可观察、可复盘的动作。执行时只把它当作建立熟悉感和互相信任的入口，不把对方当作被推进的对象。

## 关系应用

用于在社交平台上认识合适的陌生人，通过公开互动、真诚倾听和小范围互助，逐步成为朋友并赢得长期信任。

底线：必须真实透明、尊重对方选择；不伪装身份、不套取隐私、不制造虚假亲密或焦虑，对方冷淡、拒绝或沉默时停止推进。

## 执行动作

1. 触发条件：对方需要陪伴而不是小资源时。
2. 具体动作：设计 3 天或 5 天的小挑战。
3. 落地要求：把领取、打开、完成、反馈和二次对话都记录下来。
4. 边界要求：必须真实透明、尊重对方选择；不伪装身份、不套取隐私、不制造虚假亲密或焦虑，对方冷淡、拒绝或沉默时停止推进。

## 观察指标

- 挑战型小资源执行次数
- 相关内容互动率
- 后续对话或行动率
- 对方主动回应率
- 重复互动率
