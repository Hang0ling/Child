# IGS-S5-03 用 3 个诊断问题判断需求

- 阶段：S5 私信熟悉与倾听策略
- 目标：开启私信对话、提高后续对话率、形成可信专业感
- 内容形式：私信策略、资源互助策略
- 用户心理：提升专业感、提升安全感、提升被理解感
- 资料来源：[CXL Institute](https://cxl.com/institute/)、Never Split the Difference (Chris Voss)、[Google Skillshop: Fundamentals of Digital Marketing](https://skillshop.exceedlms.com/student/collection/1830706-fundamentals-of-digital-marketing)

## 核心判断

私信是更高亲密度空间，必须先让对方有选择权和安全感。有效私信不是把所有知识倒出来，而是快速定位对方所在阶段和下一步。执行时只把它当作建立熟悉感和互相信任的入口，不把对方当作被推进的对象。

## 关系应用

用于在社交平台上认识合适的陌生人，通过公开互动、真诚倾听和小范围互助，逐步成为朋友并赢得长期信任。

底线：必须真实透明、尊重对方选择；不伪装身份、不套取隐私、不制造虚假亲密或焦虑，对方冷淡、拒绝或沉默时停止推进。

## 执行动作

1. 固定 3 问：现在目标是什么、目前卡在哪里、试过什么还没用。
2. 根据答案把对方分成新手、执行中、需要关系推进优化三类。
3. 每类只给一个下一步，避免信息过载。
4. 边界要求：必须真实透明、尊重对方选择；不伪装身份、不套取隐私、不制造虚假亲密或焦虑，对方冷淡、拒绝或沉默时停止推进。

## 观察指标

- 诊断完成率
- 建议采纳率
- 后续进一步交流或领取率
- 对方主动回应率
- 重复互动率
